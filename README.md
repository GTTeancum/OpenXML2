# OpenXML2

Reconstruct X-Men Legends II PC's executable into maintainable, independently
buildable source while continuing to use the original, unchanged Alchemy DLLs.
The goal is community-extensible game code. Original executable-code fallback,
binary translation, and hooks may support development but are not completion.
Engine DLL reconstruction is outside the initial scope. XML1-specific behavior
and content compatibility are later extensions.

Project workspace: `D:\Programming\GitHub\OpenXML2`.
Game installation and runtime testing: `C:\Games\X-Men Legends II`.
Game binaries and assets are user-supplied and must not be committed.

See `docs/BINARY-ASSESSMENT.md` for the initial static inspection and `TODO.md`
for the implementation milestones. No reconstructed gameplay has been validated
yet. Calendar estimates remain provisional until measured implementation work.
